## 快速开始

### 1. 特征提取与量化

```bash
# P0阶段 - 9个基础特征（快速）
python scripts/extract_features.py --input_dir sample_wav --stage P0

# P1阶段 - 16个特征（更全面）
python scripts/extract_features.py --input_dir sample_wav --stage P1

# P2阶段 - 18个特征（完整）
python scripts/extract_features.py --input_dir sample_wav --stage P2
```

### 2. 归一化模式选择

```bash
# 同时输出自适应和固定分数（默认）
python scripts/extract_features.py --normalize_mode both

# 仅自适应归一化（基于数据分布）
python scripts/extract_features.py --normalize_mode adaptive

# 仅固定范围归一化（基于预设范围）
python scripts/extract_features.py --normalize_mode fixed
```

### 3. 输出格式

```bash
# Excel格式（推荐，包含多个Sheet）
python scripts/extract_features.py --format excel

# CSV格式
python scripts/extract_features.py --format csv

# JSON格式
python scripts/extract_features.py --format json

# 全部格式
python scripts/extract_features.py --format all
```

## 特征计算原理

### 总体分类

| 阶段 | 数量 | 类别 | 特征 |
|------|------|------|------|
| P0 | 9个 | 基础特征 | SPL_peak, K, E_low/mid/high, dB(A), N, S, R |
| P1 | 7个 | 进阶特征 | F, TI, A, TNR, SI, SK, AMD |
| P2 | 2个 | 特定特征 | ESP, NSI |

---

## P0阶段特征（9个）

### 1. SPL_peak (峰值声压级)

**计算方法：**
```
SPL_peak = 20 * log10(max(|signal|) / reference)
```
- 计算信号绝对值的最大值
- 转换为dB尺度（参考值20μPa）
- 返回相对于满量程的dB值

**合理性评估：** ⭐⭐⭐⭐
- ✅ 符合IEC 61672标准定义
- ✅ 能反映瞬时最大声压，对突发噪声敏感
- ⚠️ 对单个样本的峰值敏感，建议结合RMS使用

---

### 2. K (时域峭度)

**计算方法：**
```
K = E[(x - μ)^4] / σ^4  (fisher=False, 标准峭度)
```
- 使用scipy.stats.kurtosis计算
- fisher=False返回标准峭度（正态分布=3）
- fisher=True返回超额峭度（正态分布=0）

**合理性评估：** ⭐⭐⭐⭐⭐
- ✅ 对冲击信号极其敏感
- ✅ 是轴承、齿轮故障检测的经典指标
- ✅ 实测显示OK/NG区分度很高（Cohen's d = 4.19）

---

### 3. E_low / E_mid / E_high (频带能量占比)

**计算方法：**
```
E_band = sum(FFT_power[band_freqs]) / sum(FFT_power[all]) * 100%
```
- 频段定义：
  - E_low: 20-200Hz
  - E_mid: 200Hz-2kHz
  - E_high: 2k-20kHz
- 使用FFT计算功率谱
- 计算各频段能量占总能量百分比

**合理性评估：** ⭐⭐⭐
- ✅ 反映频谱能量分布
- ✅ 可检测特定频段异常（如低频轰鸣、高频尖锐）
- ⚠️ 当前数据显示区分度较低（Cohen's d < 0.3）
- 💡 建议：可调整为更符合人耳感知的Bark频带

---

### 4. dB(A) (A计权声压级)

**计算方法：**
```
1. 应用A计权滤波器（模拟40phon等响曲线）
2. 计算滤波后信号的RMS值
3. dB(A) = 20 * log10(RMS / 20μPa)
```
- A计权曲线：1kHz增益0dB，低频衰减，高频适度衰减
- 使用频域滤波实现（FFT后乘以A权曲线）

**合理性评估：** ⭐⭐⭐⭐⭐
- ✅ IEC 61672国际标准
- ✅ 与人耳主观响度高度相关
- ✅ 工业噪声测量的标准指标
- ⚠️ 当前实现使用简化A权曲线，精度略低于标准滤波器

---

### 5. N (响度)

**计算方法：**
```
1. 计算1/3倍频程频谱
2. 转换为Bark频域（24个临界频带）
3. 应用Zwicker响度模型：
   N' = 特定响度（考虑掩蔽效应）
   N = ∫N'(z)dz  (总响度)
```
- 使用简化Zwicker算法（mosqito库备选）
- 1 sone = 1kHz@40dB的响度感知

**合理性评估：** ⭐⭐⭐⭐
- ✅ ISO 532B国际标准（Zwicker方法）
- ✅ 比dB(A)更能反映人耳主观感受
- ✅ 考虑了频域掩蔽效应
- ⚠️ 简化实现与标准算法有偏差
- 💡 建议：使用mosqito库获得更准确结果

---

### 6. S (尖锐度)

**计算方法：**
```
S = 0.11 * ∫(N'(z) * g(z) * z * dz) / N
其中：
- N'(z): 特定响度
- g(z): Aures加权函数（高频加权）
- z: Bark频率
```
- 简化实现：基于高频能量比例
- S ≈ (E_high / E_total) * 5

**合理性评估：** ⭐⭐⭐
- ✅ DIN 45692标准
- ✅ 能有效反映高频尖锐声（如金属摩擦）
- ⚠️ 简化实现可能低估复杂信号的尖锐度
- 💡 建议：结合频谱质心可得到更稳定结果

---

### 7. R (粗糙度)

**计算方法：**
```
1. 提取信号包络（Hilbert变换）
2. 计算包络在20-300Hz的调制能量
3. R = mod_energy / total_energy * 2
```
- 关注频率：约70Hz（人耳最敏感）
- 单位：asper（1 asper = 1kHz@60dB@70Hz调制）

**合理性评估：** ⭐⭐⭐⭐
- ✅ 基于Daniel & Weber的心理声学模型
- ✅ 对调制声（如摩擦、嗡嗡声）敏感
- ✅ 实测显示较好区分度（Cohen's d = 1.63）
- ⚠️ 简化实现未考虑频域分布

## P1阶段特征（7个）

### 8. F (波动强度)

**计算方法：**
```
1. 提取信号包络（Hilbert变换）
2. 分析包络频谱 <20Hz的调制
3. F = mod_depth / (f_mod/4 + 4/f_mod)
```
- 关注频率：<20Hz（人耳可感知的波动）
- 最敏感频率：约4Hz
- 单位：vacil

**合理性评估：** ⭐⭐⭐⭐
- ✅ Zwicker & Fastl心理声学模型
- ✅ 对发动机转速波动、低频调制敏感
- ✅ 适用于检测周期性变化的声音

---

### 9. TI (音调指数)

**计算方法：**
```
1. 计算功率谱并转换为dB
2. 使用峰值检测找出频谱峰值
3. TI = Σ[(1 + peak_height/30) * (1 + sharpness/10)]
4. 对数归一化：TI = log(1 + TI) / 2
```
- 峰值高度：相对于最大峰值的dB差
- 尖锐度：峰值两侧的斜率

**合理性评估：** ⭐⭐⭐
- ✅ ECMA-418-2标准方法简化
- ✅ 能检测纯音成分（如啸叫）
- ⚠️ 对复杂多音信号可能不准确
- 💡 建议：可结合自相关法验证

---

### 10. A (烦恼度)

**计算方法：**
```
A = N * sqrt(1 + |S|) * sqrt(1 + R) / 50
其中：
- N: 响度
- S: 尖锐度
- R: 粗糙度
```
- Aures综合模型
- 综合考虑响度、尖锐度、粗糙度
- 缩放因子50将结果归一化到0-10

**合理性评估：** ⭐⭐⭐⭐
- ✅ Aures心理声学模型
- ✅ 综合多个心理声学维度
- ✅ 与主观烦恼评分相关性高
- ⚠️ 权重系数可能需要针对特定应用调整

---

### 11. TNR (音噪比)

**计算方法：**
```
1. 使用Welch方法计算功率谱密度
2. 检测频谱峰值（纯音候选）
3. 估计背景噪声（排除峰值区域的中位数）
4. TNR = peak_dB - noise_floor_dB
```
- ISO 7779 / ECMA-74标准方法
- 纯音：频谱中突出于背景噪声的窄带成分

**合理性评估：** ⭐⭐⭐⭐
- ✅ ISO 7779国际标准
- ✅ 能准确检测纯音成分
- ✅ 对啸叫、电磁噪声敏感
- ⚠️ 峰值检测阈值需要根据信噪比调整

---

### 12. SI (频谱不规则度)

**计算方法：**
```
方法1: SI1 = mean(|spec - envelope| / envelope)
方法2: SI2 = sum(|diff(spec)|) / sum(spec)
SI = (SI1 + SI2) / 2
```
- 包络：频谱的移动平均平滑
- 反映频谱偏离平滑包络的程度

**合理性评估：** ⭐⭐⭐
- ✅ Krimphoff方法
- ✅ 能检测频谱异常（如共振峰偏移）
- ⚠️ 对噪声敏感，可能需要预处理

---

### 13. SK (频谱峭度)

**计算方法：**
```
1. 计算STFT得到时变频谱
2. 对每个频率点计算峭度：
   SK(f) = kurtosis(power(t,f))
3. 加权平均（高频权重更大）
```
- Antoni & Randall方法
- 检测频域中的冲击成分

**合理性评估：** ⭐⭐⭐⭐⭐
- ✅ Antoni 2006经典算法
- ✅ 对轴承故障极其敏感
- ✅ 能定位故障频率带
- 💡 建议：结合包络解调效果更佳

---

### 14. AMD (幅度调制深度)

**计算方法：**
```
1. 提取信号包络（Hilbert变换）
2. AMD = (env_max - env_min) / (2 * env_mean) * 100%
备选: CV = std(envelope) / mean(envelope) * 100%
AMD = min(AMD, CV * 2)
```
- 反映AM调制程度
- 单位：百分比

**合理性评估：** ⭐⭐⭐
- ✅ 经典调制深度定义
- ✅ 对周期性幅度变化敏感
- ⚠️ 受信号归一化影响较大

---

## P2阶段特征（2个）

### 15. ESP (增强频谱峰值)

**计算方法：**
```
1. 计算STFT得到时变频谱
2. 计算各频率的频谱峭度SK(f)
3. 识别高SK区域（含冲击成分）
4. ESP = max(power_db[high_SK]) - median(power_db[low_SK])
```
- Randall & Antoni方法
- 结合SK定位故障频带
- 返回峰值相对于噪声的dB值

**合理性评估：** ⭐⭐⭐⭐⭐
- ✅ 结合SK和频谱峰值的先进方法
- ✅ 对轴承、齿轮故障敏感
- ✅ 能抑制噪声，突出故障特征
- 💡 建议：结合包络谱分析效果更佳

---

### 16. NSI (非平稳性指标)

**计算方法：**
```
1. 将信号分段（50ms/段）
2. 计算每段功率谱S(i,f)
3. 计算相邻段差异：
   diff(i) = mean(|S(i) - S(i-1)| / (S(i) + S(i-1)))
4. NSI = mean(diff) + 0.5*max(diff) + 0.3*std(diff)
5. 缩放至0-10范围
```
- Ravindra & Halim时频分析方法
- 反映信号特性随时间的变化程度

**合理性评估：** ⭐⭐⭐⭐
- ✅ 能有效检测间歇性噪声
- ✅ 对摩擦声、时变信号敏感
- ⚠️ 分段长度影响结果稳定性
- 💡 建议：根据信号时长调整分段参数

## 计算方式合理性评估汇总

### 高度推荐（⭐⭐⭐⭐⭐）

| 特征 | 推荐理由 |
|------|----------|
| **K (时域峭度)** | 对冲击极其敏感，实测区分度最高（Cohen's d=4.19） |
| **dB(A)** | 国际标准，与人耳感知高度相关 |

### 推荐使用（⭐⭐⭐⭐）

| 特征 | 推荐理由 |
|------|----------|
| **R (粗糙度)** | 对调制声敏感，实测区分度好（Cohen's d=1.63） |
| **N (响度)** | ISO标准，比dB(A)更贴近主观感受 |
| **A (烦恼度)** | 综合多维度，预测主观烦恼准确 |

| **F (波动强度)** | Zwicker模型，对低频波动敏感 |

## 输出格式说明

### Excel多Sheet结构

| Sheet名称 | 内容描述 |
|-----------|----------|
| 原始数据 | 各特征的原始计算值 |
| 自适应分数 | 基于数据Min-Max的0-100分 |
| 固定分数 | 基于预设范围的0-100分 |
| 范围定义 | 各特征的归一化参数 |
| 统计摘要 | OK/NG对比统计（均值、Cohen's d） |

### 分数解读

**自适应分数：**
- 基于当前数据集的分布计算
- 50分表示该批次的中等水平
- 适合同一批次数据的相对比较

**固定分数：**
- 基于声学常识的预设范围
- 50分表示一般工业噪声水平
- 适合跨数据集、跨时间的绝对比较

### Cohen's d 效应量解读

| Cohen's d | 效应大小 | 区分能力 |
|-----------|----------|----------|
| < 0.2 | 可忽略 | 差 |
| 0.2-0.5 | 小 | 一般 |
| 0.5-0.8 | 中等 | 良好 |
| 0.8-1.2 | 大 | 优秀 |
| > 1.2 | 很大 | 极好 |

## 使用建议

### 1. 特征选择建议

**快速筛选（P0阶段）：**
- 使用：dB(A), K, R
- 理由：计算快、区分度好

**详细分析（P1/P2阶段）：**
- 使用：SK, ESP, NSI, TNR
- 理由：对特定故障类型敏感

### 2. 归一化模式选择

**同批次对比：**
- 使用：adaptive模式
- 理由：突出批次内差异

**跨批次/跨时间对比：**
- 使用：fixed模式
- 理由：保持绝对参考标准

**综合评估：**
- 使用：both模式
- 理由：同时获得相对和绝对评估

### 3. 阈值设定建议

基于当前数据的OK样本分布：

```
阈值 = OK_mean + 2 * OK_std  (上阈值)
阈值 = OK_mean - 2 * OK_std  (下阈值)
```

或者使用自适应分数：
```
异常 = 固定分数 > 70 或 固定分数 < 30
```
