# SmartQuality 音频特征分析系统 - 总体设计思路

## 一、项目概述

### 1.1 目标
构建一个18维音频特征提取系统，用于汽车零部件NVH声学检测。每个音频切片输出18个特征值，形成特征向量用于NG检测。

### 1.2 核心要求
- **输入**：WAV格式音频文件（支持切片处理）
- **输出**：18维特征向量（每个特征一个数值）
- **约束**：NG样本至少有一个特征值异常（超高/超低）
- **阶段**：P0(基础) → P1(进阶) → P2(特定)

### 4.2 特征提取器基类 (base_extractor.py)

```python
from abc import ABC, abstractmethod
import numpy as np

class BaseFeatureExtractor(ABC):
    """特征提取器基类"""
    
    def __init__(self, name: str, unit: str, stage: str):
        self.name = name
        self.unit = unit
        self.stage = stage  # P0/P1/P2
    
    @abstractmethod
    def extract(self, signal: np.ndarray, sr: int) -> float:
        """提取特征值，返回单一数值"""
        pass
    
    def validate(self, value: float) -> bool:
        """验证特征值是否有效"""
        return not (np.isnan(value) or np.isinf(value))
```

### 4.5 主提取器 (feature_extractor.py)

```python
class AudioFeatureExtractor:
    """主提取器 - 管理所有18个特征"""
    
    def __init__(self, stage: str = "P0"):
        """
        stage: "P0"/"P1"/"P2" 决定提取哪些特征
        """
        self.stage = stage
        self.extractors = self._build_extractors()
    
    def _build_extractors(self) -> Dict[str, BaseFeatureExtractor]:
        """根据阶段构建提取器字典"""
        extractors = {}
        # P0特征
        extractors['dB(A)'] = AWeightedSPLExtractor()
        extractors['N'] = LoudnessExtractor()
        # ... 其他
        return extractors
    
    def extract(self, signal: np.ndarray, sr: int) -> Dict[str, float]:
        """
        提取所有特征
        返回: {特征名: 特征值}
        """
        results = {}
        for name, extractor in self.extractors.items():
            try:
                value = extractor.extract(signal, sr)
                results[name] = value
            except Exception as e:
                results[name] = None
                logger.error(f"特征 {name} 提取失败: {e}")
        return results
```
