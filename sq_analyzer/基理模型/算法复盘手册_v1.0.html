STEP 0

数据准备

将测试集分为四组，提取机理特征并标准化

FN + FP 必做
0.1 按判定结果 × 真实标签分为四组 必做 ▼
四组定义
正确预测
TP：实际合格，预测合格 TN：实际异响，预测异响
错误预测（复盘对象）
FN：合格被判异响 → 误判分析 FP：异响被判合格 → 漏检分析
量化指标
FN误判率 = FN / (TP+FN) FP漏检率 = FP / (TN+FP) FN或FP < 20条 → 扩充测试集
0.2 提取机理特征，以 TP 为基准标准化 必做 ▼
操作说明
对四组所有样本计算同一套机理特征（分贝、粗糙度、峭度、调制深度等）。 标准化基准必须用 TP（真合格）的均值和标准差，而非全体样本。
代码参考
from sklearn.preprocessing import StandardScaler

# 只用 TP 样本拟合 scaler
scaler = StandardScaler()
scaler.fit(X_tp)

X_tp_z = scaler.transform(X_tp)
X_tn_z = scaler.transform(X_tn)
X_fn_z = scaler.transform(X_fn)   # 误判样本
X_fp_z = scaler.transform(X_fp)   # 漏检样本
基准绝对不能用全体样本，否则 FP/FN 的异常信号会污染均值，导致 Z-score 失真。
STEP 1

标签噪声清洗

剔除标注错误样本，确保后续分析在干净数据上进行

FN + FP 优先执行
1.1 FN中的噪声识别：异响被误标为合格品 FN专项 ▼
逻辑
真实的合格品在所有机理维度上应和 TP 高度相似。 若一个"标签合格"样本的机理特征接近异响，大概率是标注错误。
代码参考
# 计算 FN 样本与 TP 分布的综合异常分
z_max_fn = np.abs(X_fn_z).max(axis=1)

# 异常分很高 → 可能是标注错误（实为异响被标为合格）
noise_mask = z_max_fn > 2.5
print(f"FN中疑似标注错误: {noise_mask.sum()} / {len(X_fn_z)}")

X_fn_clean = X_fn_z[~noise_mask]   # 清洗后的真实误判
X_fn_noise = X_fn_z[noise_mask]    # 待人工二次确认
判定阈值
综合异常分 > 2.5 → 疑似标注错误，人工确认 噪声比例 > 20% → 标注流程需整体审查
1.2 FP中的噪声识别：合格品被误标为异响 FP专项 ▼
逻辑
真实的异响品在机理上应和 TN 相似，与 TP 有明显差异。 若一个"标签异响"样本机理特征完全正常，大概率是误标的合格品。
代码参考
# FP 样本与 TP 的 Z-score（用 TP 基准标准化后接近0则为正常）
z_max_fp = np.abs(X_fp_z).max(axis=1)

# 综合异常分很低 → 机理完全正常 → 疑似标注错误
noise_mask_fp = z_max_fp < 1.0
print(f"FP中疑似标注错误: {noise_mask_fp.sum()} / {len(X_fp_z)}")

X_fp_clean = X_fp_z[~noise_mask_fp]  # 真实漏检
X_fp_noise = X_fp_z[noise_mask_fp]   # 待人工确认
判定阈值
综合异常分 < 1.0 → 机理完全正常，疑似误标 人工确认后清洗，不进入后续分析
STEP 2a

FN 误判分析

分析合格品被误判为异响的原因 · 召回率问题

FN专项
2a.1 机理特征分布对比：FN vs TP 可视化 ▼
操作
对每个机理特征，绘制 TP / FN / TN 三组的箱线图或小提琴图。 核心问题：FN 的特征分布更接近 TP 还是 TN？
代码参考
import seaborn as sns

df['group'] = labels.map({'TP':'合格(TP)', 'FN':'误判(FN)', 'TN':'异响(TN)'})
for feat in features:
    sns.violinplot(data=df, x='group', y=feat, inner='box')
判定分支
FN ≈ TP 分布
机理正常，模型误判 → 决策边界问题 → 进入 2a.2 定位原因
FN 介于 TP 和 TN 之间
边界样本，特征模糊 → 模型在此区域不确定 → 进入 2a.2
2a.2 置信度分布：定位误判类型 诊断 ▼
代码参考
# 模型对 FN 样本输出的异响概率（越高说明越自信地判错）
conf = model.predict_proba(X_fn)[:, 1]  # 异响概率
plt.hist(conf, bins=20)
plt.axvline(0.5, color='red', linestyle='--')
判定分支
置信度集中在 0.5 附近
情况A：边界样本不足 → 该区域训练数据稀疏 → 补充边界区域合格样本
置信度集中在 0.8+
情况C：分布偏移 → 模型系统性误判 → KS检验定位偏移特征
2a.3 情况A：百分位分析定位补数据区间 情况A ▼
代码参考
from scipy.stats import percentileofscore

for i, feat in enumerate(features):
    pcts = [percentileofscore(X_tp[:,i], v)
            for v in X_fn[:,i]]
    p90 = np.percentile(pcts, 90)

判定阈值
百分位 > 90% → 该特征高值区域缺少训练样本 不要调低模型阈值来掩盖，会导致特异性下降
2a.4 情况C：KS检验定位分布偏移特征 情况C ▼
代码参考

STEP 2b

FP 漏检分析

分析异响品未被检出的原因 · 特异性问题 · 优先级最高

FP专项 ⚠ 优先处理
2b.1 机理信号强度分析：漏检样本有无可识别信号 核心诊断 ▼
核心问题
模型是"有信号没抓到"还是"信号本来就很弱"？ 计算漏检 FP 样本与 TP 的 Cohen's d（各机理维度）。
代码参考
def cohens_d(a, b):
    pooled = np.sqrt((a.std()**2 + b.std()**2) / 2)
    return abs(a.mean() - b.mean()) / pooled

for i, feat in enumerate(features):
    d = cohens_d(X_fp_clean[:,i], X_tp[:,i])
    tag = '强信号' if d > 0.8 else ('中等' if d > 0.5 else '弱信号')
    print(f"{feat:20s}  d={d:.2f}  {tag}")
判定分支
d > 0.8（强信号）
机理可区分，是模型问题 → 进入 2b.2 分析漏检规律
d 0.5–0.8（中等）
模型和特征都可能有问题 → 进入 2b.2，同时记录待优化特征
d < 0.5（弱信号）
当前特征无法描述此类缺陷 → 需要设计新特征维度 → 进入 2b.3
2b.2 漏检规律性分析：随机还是系统性漏检 信号强时执行 ▼
方向一：聚类分析
from sklearn.cluster import DBSCAN
from sklearn.metrics import silhouette_score

# 对漏检样本做聚类，看是否有系统性缺陷子类
db = DBSCAN(eps=0.5, min_samples=3)
cluster_labels = db.fit_predict(X_fp_clean)

n_clusters = len(set(cluster_labels)) - (1 if -1 in cluster_labels else 0)
print(f"发现 {n_clusters} 个漏检聚类")

if n_clusters > 1:
    score = silhouette_score(X_fp_clean, cluster_labels)
    print(f"轮廓系数: {score:.3f}")  # > 0.4 说明聚类结构清晰
判定分支
轮廓系数 > 0.4
存在系统性漏检缺陷子类 → 分析各 cluster 主导特征 → 针对性补充该类样本
轮廓系数 < 0.4
漏检分散无规律 → 模型整体特异性设置问题 → 调整损失函数权重
2b.3 弱信号处理：设计新特征维度 信号弱时执行 ▼
操作
当前机理特征集无法描述该类漏检缺陷，需要结合领域知识设计新维度。 常见方向：
时频联合特征（短时傅里叶 / 小波） 调制特征（AM/FM 解调深度） 心理声学特征（响度、尖锐度） 统计矩（偏度、峰度的高阶组合）
新特征设计后需重新跑 Step 2b.1 的 Cohen's d 验证是否有效，d > 0.8 才值得加入特征集。
STEP 3

FN + FP 联合特征空间分析

将两类错误投影到同一空间，分析相互关系与 trade-off

FN + FP
3.1 PCA / UMAP 四组联合可视化 关键步骤 ▼
操作说明
将 TP / TN / FN / FP 四组合并降维，在同一张图上观察位置关系。 这是判断 FN 和 FP 是否源于同一边界问题的关键步骤。
代码参考
X_all = np.vstack([X_tp_z, X_tn_z, X_fn_z, X_fp_z])
labels_all = (
    ['TP']*len(X_tp_z) + ['TN']*len(X_tn_z) +
    ['FN']*len(X_fn_z) + ['FP']*len(X_fp_z)
)

pca = PCA(n_components=2)

colors = {'TP':'#10b981', 'TN':'#3b82f6',
          'FN':'#6B5EE4', 'FP':'#ef4444'}
markers = {'TP':'o', 'TN':'s', 'FN':'^', 'FP':'x'}
观察要点
FN 和 FP 都聚集在决策边界附近
两类错误是同一边界问题的两面 → 调整边界会同时影响 FN 和 FP → 需要权衡，以降低 FP 为优先
FN 和 FP 位于不同区域
两类问题相互独立 → 可以分别处理，互不干扰
FP 形成独立 cluster 远离 TN
系统性漏检特定缺陷类型 → 对应 2b.2 的聚类结果 → 针对性补充该类训练样本
3.2 Trade-off 量化：调整边界对 FN/FP 的影响 权衡评估 ▼
操作
绘制不同分类阈值下的 特异性 vs 召回率 曲线（ROC 曲线）， 找到在满足特异性约束条件下，召回率最大的工作点。
代码参考
from sklearn.metrics import roc_curve

fpr, tpr, thresholds = roc_curve(y_true, y_prob)
# fpr = FP率 = 1 - 特异性，tpr = 召回率

# 找到特异性 ≥ 0.95 时的最大召回率工作点
specificity = 1 - fpr
valid = specificity >= 0.95
best_idx = tpr[valid].argmax()
best_thresh = thresholds[valid][best_idx]
print(f"推荐阈值: {best_thresh:.3f}")
print(f"特异性: {specificity[valid][best_idx]:.3f}")
print(f"召回率: {tpr[valid][best_idx]:.3f}")
业务优先级：特异性优先（FP=0是目标），在特异性约束满足的前提下再最大化召回率。

STEP 5

机理严重度验证

验证机理评分系统对漏检样本的严重度输出是否合理

FP重点
5.1 计算漏检样本的机理严重度分 FP专项 ▼
逻辑
即使被分类模型漏检，机理评分系统应能给出合理的严重度排序。 各维度超过阈值 → 触发对应严重度，任意一个超过 → 判为异响（OR逻辑）。
代码参考
# 对每个漏检样本计算各维度是否超过机理阈值
for feat, thresh in thresholds.items():
    triggered = (X_fp[feat] > thresh).mean()
    print(f"{feat}: {triggered:.1%} 的漏检样本触发阈值")

# 综合严重度：取各维度 Z-score 的加权和
severity = (X_fp_z * weights).sum(axis=1)
print(f"严重度分布: min={severity.min():.2f} max={severity.max():.2f}")
判定分支
严重度分布合理（有高有低）
机理评分体系有效 → 漏检问题在分类模型侧解决 → 机理评分侧无需调整
严重度普遍偏低（系统性低估）
机理阈值设置偏高 → 重新标定阈值 → 重点关注轻微缺陷区间
部分样本严重度为 0
对应情况：弱信号 (d < 0.5) → 现有特征无法描述该缺陷 → 需要新特征维度（2b.3）
